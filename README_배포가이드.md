# 📈 종목선정 스캐너 — 아이폰/아이패드에서 쓰는 방법

아이폰·아이패드에는 파이썬을 직접 설치할 수 없기 때문에, 이 프로그램을 **인터넷 위(클라우드)에 한 번 올려두고** 사파리로 접속하는 방식을 씁니다.
가장 쉽고 무료인 방법이 **Streamlit Community Cloud** 입니다. 한 번만 해두면 이후엔 홈 화면 아이콘만 누르면 됩니다.

준비물: 이메일 하나 (GitHub 가입용) · 약 15분

---

## 1단계. GitHub 계정 만들기 (무료)
1. https://github.com 접속 → **Sign up** → 이메일/비밀번호 입력, 인증
2. 로그인 후 오른쪽 위 **+** → **New repository**
3. Repository name: `stock-scanner` 입력 → **Public** 선택 → **Create repository**

## 2단계. 파일 3개 올리기
1. 방금 만든 저장소 화면에서 **Add file → Upload files**
2. 아래 3개 파일을 끌어다 놓기(또는 choose your files)
   - `app.py`
   - `requirements.txt`
   - `README_배포가이드.md` (이 파일, 선택)
3. 아래 **Commit changes** 클릭

## 3단계. Streamlit Community Cloud에 연결 (무료)
1. https://share.streamlit.io 접속 → **Continue with GitHub** 로 로그인 (권한 허용)
2. **Create app** (또는 New app) 클릭
3. 설정 입력
   - Repository: `본인아이디/stock-scanner`
   - Branch: `main`
   - Main file path: `app.py`
4. **Deploy** 클릭 → 2~5분 기다리면 `https://xxxx.streamlit.app` 주소가 생깁니다

## 4단계. 아이폰/아이패드 홈 화면에 앱처럼 추가
1. 사파리에서 위 주소 열기
2. 하단 **공유 버튼(□↑)** → **홈 화면에 추가** → 이름 "종목스캐너" → 추가
3. 이제 홈 화면 아이콘을 누르면 앱처럼 바로 열립니다

## 매일 쓰는 방법 (책의 STEP 기준)
| 시간 | 할 일 |
|---|---|
| 12:30 이후 | 앱 열기 → 🇰🇷 국내 → KOSPI/KOSDAQ 선택 → **지금 스캔하기** |
| | ✅ 매수후보 / 👀 관찰 종목 확인 → **종목 상세** 탭에서 차트 직접 확인 |
| 14:00 | 재스캔 → 3~5개 → 최종 1~2개로 압축 |
| 14:30 이후 | 호가창 보고 저가 지정가 또는 종가 부근 매수 |
| 보유 중 | 소형주 +10% / 대형주 +5% 이익실현 · 지지선 붕괴+거래량 급증 시에만 손절 |

## 자주 묻는 것
- **첫 접속이 느려요** → 무료 서버는 한동안 안 쓰면 잠들었다가 깨어나는 데 30초~1분 걸립니다. 정상입니다.
- **스캔이 오래 걸려요** → "등락률 상위 N개"를 30개 이하로 줄이세요.
- **종목이 하나도 안 나와요** → 휴장일이거나 장 시작 직후일 수 있습니다. 12:30 이후 다시 시도하세요.
- **PC에서 직접 실행하려면** → 파이썬 설치 후 터미널에서
  `pip install -r requirements.txt` → `streamlit run app.py`
